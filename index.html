블로그의 진화 - 멀티미디어와 콘텐츠의 融合

📅 2026년 8월 13일 💡 웹 개발 | 포트폴리오 개선

🌟 들어가며

개인 포트폴리오 웹사이트를 개선하는 과정은 단순한 코드 리팩토링을 넘어 사용자 경험과 창작 철학을 재정의하는 과정이다. 이 글에서는 Unorthodox-oddball.github.io의 전면적인 개선 여정을 기록한다.

🔍 문제 인식: 불필요한 제약

기존 코드의 문제점:

  • ❌ F12 키 차단 - 개발자 도구 접근 제한
  • ❌ 우클릭 차단 - 기본적인 브라우저 기능 박탈
  • ❌ Ctrl 키 차단 - 복사/붙여넣기 기능 제한
  • ❌ 드래그 차단 - 사용자 상호작용 제한

이러한 제약들은 "보안"이라는 명목 하에 사용자의 기본적인 브라우저 자유도를 침해하고 있었다.

🎬 멀티미디어 × 블로그의 새로운 패러다임

기존의 순수 텍스트 기반 블로그에서 벗어나, 이미지, GIF, 음악, 그리고 인터랙티브 요소를 블로그 콘텐츠와 자연스럽게 통합하는 방식을 모색했다.

핵심 개념: 콘텐츠는 단순한 텍스트가 아니라, 시각, 청각, 그리고 상호작용을 통해 다층적인 의미를 전달하는 매체가 되어야 한다.

⚙️ 기술적 개선사항

1️⃣ test.js 리팩토링

제거된 코드:

  • F12 키 이벤트 리스너 제거
  • 우클릭 방지 이벤트 제거
  • 드래그 방지 이벤트 제거
  • Ctrl 키 제한 제거

추가된 기능:

  • ✨ switchTab() 함수 - 탭 전환 네비게이션
  • ✨ 동적 탭 활성화/비활성화 시스템
  • ✨ 스타일시트 자동 로드
  • ✨ 배경음악 자동 재생

2️⃣ index.html 구조 개선

  • 📑 새로운 네비게이션 탭 시스템 도입
  • 📑 "Blog" 탭 - 기존 블로그 글들
  • 📑 "Experiments" 탭 - 실험적 콘텐츠
  • 📑 SEO 메타데이터 추가
  • 📑 접근성 개선 (Semantic HTML)

3️⃣ CSS 최적화

  • 🎨 중괄호 중복 오류 수정 (라인 122)

  • 🎨 반응형 디자인 강화
  • 🎨 색상 팔레트 일관성 유지

💭 왜 이런 변화가 필요했나?

포트폴리오는 단순한 이력서의 디지털 버전이 아니다. 그것은 창작자의 사고방식, 미학, 그리고 철학을 보여주는 창이다.

  • 제약 제거: 사용자를 신뢰하고, 그들의 자유도를 존중하는 것이 결과적으로 더 나은 사용자 경험을 만든다.
  • 멀티미디어 통합: 텍스트만으로는 전할 수 없는 감정과 의도를 시각과 음향으로 보완한다.
  • 실험성 강조: "Experiments" 탭을 통해 진행 중인 작업과 미래의 방향성을 명확히 한다.

✨ 마치며

이번 개선 과정은 단순한 코드 리팩토링이 아니었다. 그것은 웹 창작의 자유도를 되찾고, 멀티미디어라는 새로운 표현 도구를 활용하며, 포트폴리오를 통해 자신의 철학을 드러내는 작업이었다.

앞으로 이 블로그는 단순한 정보 전달의 매체를 넘어, 시각, 청각, 그리고 사고의 영역이 만나는 공간이 될 것이다.
